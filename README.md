# IGCSE Computer Science 0478 – Chapter 4: Software

Interactive learning rooms for sections 4.1 and 4.2, plus three practice computers that run in the browser.

| Folder | What it is |
|---|---|
| `index.html` | The Chapter 4 lesson (all sections) |
| `win7/` | Windows 7 GUI simulation |
| `cmd/` | Practice Windows Command Prompt |
| `linux/` | Real Linux (Alpine) running in the browser with the v86 emulator |

All of these must be uploaded together, keeping the folder names, so the links work.
